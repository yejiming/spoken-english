# 485-already-over-it Already Over It

- 场景: Feelings & Opinions / 感受观点
- 句型: I'm already over ...
- 意思: 已经无所谓了
- 用法: 用于说对某事已经不再介意。

## 例句

1. I'm already over the drama from last week.
   - 上周的那些事我已经无所谓了。

2. I'm already over that failed experiment.
   - 那次失败的实验我已经无所谓了。

3. I'm already over missing the sale.
   - 错过那次打折我已经无所谓了。

4. I'm already over the bad review I got.
   - 收到的差评我已经无所谓了。

5. I'm already over the argument we had.
   - 我们的争吵我已经无所谓了。
