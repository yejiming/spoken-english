# 024-might-as-well Might As Well

- 场景: Daily Life / 日常生活
- 句型: I might as well ... while I'm here.
- 意思: 顺便做某事
- 用法: 用于表示既然已经在某处，不如顺便做点什么。

## 例句

1. I might as well grab some coffee while I'm here.
   - 既然来了我就顺便买杯咖啡吧。

2. I might as well check the mail while I'm here.
   - 既然来了我就顺便看看邮件吧。

3. I might as well pick up some groceries while I'm here.
   - 既然来了我就顺便买点菜吧。

4. I might as well get my hair cut while I'm here.
   - 既然来了我就顺便理个发吧。

5. I might as well return this book while I'm here.
   - 既然来了我就顺便把书还了吧。
