# 225-bringing-someone Bringing Someone

- 场景: Social Plans / 社交安排
- 句型: I'm bringing ... if that's cool.
- 意思: 顺便带个人
- 用法: 用于告知别人你会带朋友来，征求对方意见。

## 例句

1. I'm bringing my roommate if that's cool.
   - 我带我室友来，没问题吧？

2. I'm bringing my boyfriend if that's cool.
   - 我把男朋友带来，行吗？

3. I'm bringing my cousin if that's cool.
   - 我带表弟来，可以吧？

4. I'm bringing a friend from work if that's cool.
   - 我带个同事来，没事吧？

5. I'm bringing my dog if that's cool.
   - 我带我的狗来，行吧？
