# 085-snacking-on Snacking On

- 场景: Daily Life / 日常生活
- 句型: I've been snacking on ... all day.
- 意思: 一整天都在吃
- 用法: 用于表示你一整天都在吃某种零食。

## 例句

1. I've been snacking on chips all day.
   - 我一整天都在吃薯片。

2. I've been snacking on crackers all day.
   - 我一整天都在吃饼干。

3. I've been snacking on fruit all day.
   - 我一整天都在吃水果。

4. I've been snacking on trail mix all day.
   - 我一整天都在吃混合坚果。

5. I've been snacking on chocolate all day.
   - 我一整天都在吃巧克力。
