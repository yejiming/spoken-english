# 25-waiting-for Waiting For

- 场景: Work & School / 工作学习
- 句型: I'm waiting for ...
- 意思: 在等回复或结果。
- 用法: 用于说你正在等待。

## 例句

1. I'm waiting for the typo
   - 我在等这个错字。

2. I'm waiting for class prep
   - 我在等备课。

3. I'm waiting for the comments
   - 我在等这些批注。

4. I'm waiting for the handout
   - 我在等讲义。

5. I'm waiting for the summary
   - 我在等总结。
