# 308-not-sure-how Not Sure How

- 场景: Problems & Solutions / 问题处理
- 句型: I'm not sure how to ...
- 意思: 不确定怎么做
- 用法: 用于表达你不知道某件事的操作方法。

## 例句

1. I'm not sure how to set up the new router.
   - 我不太确定怎么装新路由器。

2. I'm not sure how to export this file as a PDF.
   - 我不太确定怎么把文件导出成PDF。

3. I'm not sure how to reset my password.
   - 我不太确定怎么重置密码。

4. I'm not sure how to change the default settings.
   - 我不太确定怎么改默认设置。

5. I'm not sure how to pair my headphones with the TV.
   - 我不太确定怎么把耳机和电视配对。
