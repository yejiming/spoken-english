# 79-just-want-to-make-sure Just Want To Make Sure

- 场景: Problems & Solutions / 问题处理
- 句型: I just want to make sure ...
- 意思: 先求稳。
- 用法: 用于强调你要确认。

## 例句

1. I just want to make sure use the old cable
   - 我只是想确认用那根旧电缆。

2. I just want to make sure find a backup plan
   - 我只是想确认找备用方案。

3. I just want to make sure the wifi to connect
   - 我只是想确认Wi-Fi 连接。

4. I just want to make sure miss the deadline
   - 我只是想确认错过截止时间。

5. I just want to make sure lose the progress
   - 我只是想确认丢掉进度。
