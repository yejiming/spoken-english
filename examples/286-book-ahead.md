# 286-book-ahead Book Ahead

- 场景: Social Plans / 社交安排
- 句型: Should we book ... ahead of time?
- 意思: 要不要提前订
- 用法: 用于询问是否需要提前预订。

## 例句

1. Should we book a table ahead of time?
   - 要不要提前订个位子？

2. Should we book tickets ahead of time?
   - 要不要提前买票？

3. Should we book a hotel ahead of time?
   - 要不要提前订酒店？

4. Should we book an Uber ahead of time?
   - 要不要提前约车？

5. Should we book the karaoke room ahead of time?
   - 要不要提前订KTV包间？
