# 48-let-you-know Let You Know

- 场景: Social Plans / 社交安排
- 句型: I'll let you know if I can ...
- 意思: 先保留可能性。
- 用法: 用于给对方一个答复。

## 例句

1. I'll let you know if I can catch a movie
   - 如果我能看电影，我会告诉你。

2. I'll let you know if I can meet for coffee
   - 如果我能见面喝咖啡，我会告诉你。

3. I'll let you know if I can go for a walk
   - 如果我能散步，我会告诉你。

4. I'll let you know if I can check out the new place
   - 如果我能去看看那家新店，我会告诉你。

5. I'll let you know if I can hang out
   - 如果我能一起待着，我会告诉你。
