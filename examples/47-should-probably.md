# 47-should-probably Should Probably

- 场景: Social Plans / 社交安排
- 句型: We should probably ... first.
- 意思: 先做准备。
- 用法: 用于建议先做某事。

## 例句

1. We should probably grab drinks first.
   - 我们最好先喝点东西。

2. We should probably plan something low-key first.
   - 我们最好先计划轻松一点的活动。

3. We should probably grab dinner first.
   - 我们最好先吃晚饭。

4. We should probably catch a movie first.
   - 我们最好先看电影。

5. We should probably meet for coffee first.
   - 我们最好先见面喝咖啡。
