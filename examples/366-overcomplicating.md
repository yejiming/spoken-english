# 366-overcomplicating Overcomplicating

- 场景: Problems & Solutions / 问题处理
- 句型: I think I'm overcomplicating ...
- 意思: 想复杂了
- 用法: 用于说可能把问题想得太复杂。

## 例句

1. I think I'm overcomplicating this math problem.
   - 我觉得我把这道数学题想复杂了。

2. I think I'm overcomplicating the setup process.
   - 我觉得我把安装过程想复杂了。

3. I think I'm overcomplicating the recipe.
   - 我觉得我把这道菜的做法想复杂了。

4. I think I'm overcomplicating the project structure.
   - 我觉得我把项目结构想复杂了。

5. I think I'm overcomplicating my morning routine.
   - 我觉得我把早上的流程想复杂了。
