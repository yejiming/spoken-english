# 011-already-done Already Done

- 场景: Daily Life / 日常生活
- 句型: I've already ...
- 意思: 已经完成了
- 用法: 用于说明事情已经做完。

## 例句

1. I've already called my parents.
   - 我已经给父母打过电话了。

2. I've already paid the electricity bill.
   - 我已经付过电费了。

3. I've already taken out the trash.
   - 我已经把垃圾倒了。

4. I've already fed the cat.
   - 我已经喂过猫了。

5. I've already done the laundry.
   - 我已经洗好衣服了。
