# 270-already-rsvp-d Already RSVP'd

- 场景: Social Plans / 社交安排
- 句型: I already RSVP'd for ...
- 意思: 已经报名了
- 用法: 用于表示你已经确认参加某个活动。

## 例句

1. I already RSVP'd for the gala.
   - 我已经报名参加晚宴了。

2. I already RSVP'd for the workshop.
   - 我已经报名研讨会了。

3. I already RSVP'd for the rooftop party.
   - 我已经报名天台派对了。

4. I already RSVP'd for the wine tasting.
   - 我已经报名品酒会了。

5. I already RSVP'd for the charity run.
   - 我已经报名慈善跑了。
