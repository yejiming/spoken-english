# 453-fed-up-with Fed Up With

- 场景: Feelings & Opinions / 感受观点
- 句型: I'm fed up with ...
- 意思: 忍无可忍了
- 用法: 用于说对某事已经忍到极限。

## 例句

1. I'm fed up with the noisy neighbors upstairs.
   - 楼上吵闹的邻居我忍无可忍了。

2. I'm fed up with the constant app updates.
   - 应用不停更新我忍无可忍了。

3. I'm fed up with waiting in traffic every day.
   - 每天堵车我忍无可忍了。

4. I'm fed up with being put on hold for an hour.
   - 被挂电话等一小时我忍无可忍了。

5. I'm fed up with the unreliable delivery service.
   - 不靠谱的快递我忍无可忍了。
