# 90-excited-about Excited About

- 场景: Feelings & Opinions / 感受观点
- 句型: I'm excited about ...
- 意思: 期待感很强。
- 用法: 用于说你很期待。

## 例句

1. I'm excited about moving to a new place
   - 我对搬去新地方很兴奋。

2. I'm excited about keeping things simple
   - 我对保持简单很兴奋。

3. I'm excited about a crowded room
   - 我对一个拥挤的房间很兴奋。

4. I'm excited about the new layout
   - 我对新版布局很兴奋。

5. I'm excited about getting up early
   - 我对早起很兴奋。
