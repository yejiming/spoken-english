# 87-pretty-sure Pretty Sure

- 场景: Feelings & Opinions / 感受观点
- 句型: I'm pretty sure ... is going to work.
- 意思: 对结果有把握。
- 用法: 用于表达很有信心。

## 例句

1. I'm pretty sure trying something new is going to work.
   - 我很确定尝试新事物会奏效。

2. I'm pretty sure the way this feels is going to work.
   - 我很确定这种感觉会奏效。

3. I'm pretty sure staying home tonight is going to work.
   - 我很确定今晚待在家会奏效。

4. I'm pretty sure the new restaurant is going to work.
   - 我很确定那家新餐厅会奏效。

5. I'm pretty sure working from home is going to work.
   - 我很确定在家办公会奏效。
