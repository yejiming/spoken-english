# 002-about-to-start About to Start

- 场景: Daily Life / 日常生活
- 句型: I'm about to ...
- 意思: 马上就要开始做
- 用法: 用于说你马上要做某事。

## 例句

1. I'm about to hop in the shower.
   - 我正要去洗澡。

2. I'm about to head out the door.
   - 我正要出门。

3. I'm about to start cooking dinner.
   - 我正要开始做晚饭。

4. I'm about to take the dog for a walk.
   - 我正要带狗去散步。

5. I'm about to call my mom back.
   - 我正要给我妈回电话。
