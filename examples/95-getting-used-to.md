# 95-getting-used-to Getting Used To

- 场景: Feelings & Opinions / 感受观点
- 句型: I'm getting used to ...
- 意思: 还在适应。
- 用法: 用于说你在适应。

## 例句

1. I'm getting used to working from home
   - 我正在慢慢习惯在家办公。

2. I'm getting used to people being late
   - 我正在慢慢习惯别人迟到。

3. I'm getting used to taking a break
   - 我正在慢慢习惯休息一下。

4. I'm getting used to trying the spicy noodles
   - 我正在慢慢习惯尝试辣面。

5. I'm getting used to having more time
   - 我正在慢慢习惯拥有更多时间。
