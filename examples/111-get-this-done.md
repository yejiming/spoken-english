# 111-get-this-done Get This Done

- 场景: Work & School / 工作学习
- 句型: I need to get this ... done.
- 意思: 得把这事做完
- 用法: 用于表达你必须完成手头的某件事。

## 例句

1. I need to get this proposal done.
   - 我得把这份提案做完。

2. I need to get this essay done.
   - 我得把这篇文章写完。

3. I need to get this code review done.
   - 我得把这次代码审查做完。

4. I need to get this expense report done.
   - 我得把这份报销单填完。

5. I need to get this group project done.
   - 我得把这个小组项目完成。
