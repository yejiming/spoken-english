# 50-hoping-to Hoping To

- 场景: Social Plans / 社交安排
- 句型: I'm hoping to ... this weekend.
- 意思: 周末愿望。
- 用法: 用于说你很想做。

## 例句

1. I'm hoping to have a quick chat this weekend.
   - 我希望这周末能聊几句。

2. I'm hoping to stop by later this weekend.
   - 我希望这周末能待会儿顺路过去。

3. I'm hoping to pick you up this weekend.
   - 我希望这周末能接你。

4. I'm hoping to swing by the cafe this weekend.
   - 我希望这周末能顺路去咖啡馆。

5. I'm hoping to make a reservation this weekend.
   - 我希望这周末能订座位。
