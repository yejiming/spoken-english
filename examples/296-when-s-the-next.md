# 296-when-s-the-next When's The Next

- 场景: Social Plans / 社交安排
- 句型: When's the next time we can ...?
- 意思: 下次什么时候
- 用法: 用于询问大家下次有空一起做某事的时间。

## 例句

1. When's the next time we can all hang out?
   - 咱们下次什么时候能聚？

2. When's the next time we can go camping?
   - 下次什么时候能去露营？

3. When's the next time we can do this again?
   - 下次什么时候能再这样聚？

4. When's the next time we can grab dinner?
   - 下次什么时候能一起吃饭？

5. When's the next time we can play tennis?
   - 下次什么时候能一起打网球？
