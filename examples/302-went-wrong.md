# 302-went-wrong Went Wrong

- 场景: Problems & Solutions / 问题处理
- 句型: Something went wrong with ...
- 意思: 某个地方出错
- 用法: 用于说明哪个部分出了故障。

## 例句

1. Something went wrong with the software update.
   - 软件更新出了问题。

2. Something went wrong with the payment.
   - 付款出了问题。

3. Something went wrong with the printer.
   - 打印机出了问题。

4. Something went wrong with the file transfer.
   - 文件传输出了问题。

5. Something went wrong with the reservation system.
   - 预订系统出了问题。
