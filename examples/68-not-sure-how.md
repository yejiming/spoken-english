# 68-not-sure-how Not Sure How

- 场景: Problems & Solutions / 问题处理
- 句型: I'm not sure how to ...
- 意思: 还不清楚办法。
- 用法: 用于说你不会操作。

## 例句

1. I'm not sure how to log in
   - 我不太确定怎么登录。

2. I'm not sure how to send the file
   - 我不太确定怎么发送文件。

3. I'm not sure how to connect the printer
   - 我不太确定怎么连接打印机。

4. I'm not sure how to save the changes
   - 我不太确定怎么保存更改。

5. I'm not sure how to clear the cache
   - 我不太确定怎么清理缓存。
