# 312-check-whether Check Whether

- 场景: Problems & Solutions / 问题处理
- 句型: Let me check whether ...
- 意思: 让我查查看
- 用法: 用于表达你要去确认某个情况。

## 例句

1. Let me check whether the warranty is still valid.
   - 让我查查保修是不是还有效。

2. Let me check whether they have the part in stock.
   - 让我查查他们有没有这个零件的库存。

3. Let me check whether the backup finished.
   - 让我查查备份是不是已经完成了。

4. Let me check whether the refund has been processed.
   - 让我查查退款有没有处理好。

5. Let me check whether the technician is available today.
   - 让我查查技术人员今天有没有空。
