# 307-keep-getting Keep Getting

- 场景: Problems & Solutions / 问题处理
- 句型: I keep getting an error when I ...
- 意思: 每次操作都报错
- 用法: 用于描述重复出现的错误。

## 例句

1. I keep getting an error when I try to save the file.
   - 我每次保存文件都会报错。

2. I keep getting an error when I open the app.
   - 我每次打开应用都会报错。

3. I keep getting an error when I connect the Bluetooth.
   - 我每次连蓝牙都会报错。

4. I keep getting an error when I log into the website.
   - 我每次登录网站都会报错。

5. I keep getting an error when I run the update.
   - 我每次运行更新都会报错。
