# 047-catching-up-on Catching Up On

- 场景: Daily Life / 日常生活
- 句型: I'm catching up on ...
- 意思: 在补做某事
- 用法: 用于表示你正在把之前落下的事情补上。

## 例句

1. I'm catching up on sleep this weekend.
   - 我这个周末在补觉。

2. I'm catching up on my emails.
   - 我在补回邮件。

3. I'm catching up on that TV show.
   - 我在补那部剧。

4. I'm catching up on the news.
   - 我在补看新闻。

5. I'm catching up on housework.
   - 我在补做家务。
