# 371-holding-things-up Holding Things Up

- 场景: Problems & Solutions / 问题处理
- 句型: This is holding up ...
- 意思: 卡住进度了
- 用法: 用于说某事阻碍了整体进度。

## 例句

1. This is holding up the entire project timeline.
   - 这卡住了整个项目进度。

2. This is holding up the product launch.
   - 这卡住了产品上线的进度。

3. This is holding up everyone else's work.
   - 这卡住了其他人的工作进度。

4. This is holding up the delivery schedule.
   - 这卡住了配送安排。

5. This is holding up the approval process.
   - 这卡住了审批流程。
