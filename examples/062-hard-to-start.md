# 062-hard-to-start Hard To Start

- 场景: Daily Life / 日常生活
- 句型: It's so hard to ... in the morning.
- 意思: 早上很难做到
- 用法: 用于表达早上做某件事特别困难。

## 例句

1. It's so hard to get out of bed in the morning.
   - 早上起床太难了。

2. It's so hard to focus in the morning.
   - 早上集中注意力太难了。

3. It's so hard to eat healthy in the morning.
   - 早上吃得健康太难了。

4. It's so hard to be productive in the morning.
   - 早上想高效做事太难了。

5. It's so hard to stay positive in the morning.
   - 早上保持好心情太难了。
