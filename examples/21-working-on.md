# 21-working-on Working On

- 场景: Work & School / 工作学习
- 句型: I'm working on ... right now.
- 意思: 正在进行中的工作。
- 用法: 用于说你此刻正在忙什么。

## 例句

1. I'm working on finishing this report right now.
   - 我现在正在处理完成这份报告。

2. I'm working on replying to those emails right now.
   - 我现在正在处理回复那些邮件。

3. I'm working on the meeting prep right now.
   - 我现在正在处理会议准备。

4. I'm working on taking notes right now.
   - 我现在正在处理做笔记。

5. I'm working on the slides right now.
   - 我现在正在处理这些幻灯片。
