# 207-should-probably Should Probably

- 场景: Social Plans / 社交安排
- 句型: We should probably ... first.
- 意思: 我们应该先做
- 用法: 用于建议在做某事之前先完成另一件事。

## 例句

1. We should probably make a reservation first.
   - 我们应该先订个位。

2. We should probably check the weather first.
   - 我们应该先看看天气。

3. We should probably eat something first.
   - 我们应该先吃点东西。

4. We should probably ask her if she's free first.
   - 我们应该先问问她有没有空。

5. We should probably figure out a meeting spot first.
   - 我们应该先确定碰面的地方。
