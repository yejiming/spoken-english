# 351-forgot-password Forgot Password

- 场景: Problems & Solutions / 问题处理
- 句型: I forgot my password for ...
- 意思: 忘了密码
- 用法: 用于说忘记了某个账户的密码。

## 例句

1. I forgot my password for the company portal.
   - 我忘了公司平台的密码。

2. I forgot my password for my old email.
   - 我忘了旧邮箱的密码。

3. I forgot my password for the streaming service.
   - 我忘了流媒体账号的密码。

4. I forgot my password for the school Wi-Fi.
   - 我忘了学校Wi-Fi的密码。

5. I forgot my password for the cloud storage.
   - 我忘了云存储的密码。
