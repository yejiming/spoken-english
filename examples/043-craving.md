# 043-craving Craving

- 场景: Daily Life / 日常生活
- 句型: I've been craving ...
- 意思: 一直很想吃
- 用法: 用于表达你最近特别想吃某种食物。

## 例句

1. I've been craving pizza all week.
   - 我整个星期都特别想吃披萨。

2. I've been craving something spicy.
   - 我一直特别想吃辣的。

3. I've been craving fried chicken.
   - 我一直特别想吃炸鸡。

4. I've been craving ice cream lately.
   - 我最近特别想吃冰淇淋。

5. I've been craving ramen nonstop.
   - 我一直馋拉面。
