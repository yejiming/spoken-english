# 209-confirm-whether Confirm Whether

- 场景: Social Plans / 社交安排
- 句型: I need to confirm whether we can ...
- 意思: 确认能不能行
- 用法: 用于表达你需要先确认某件事情是否可行。

## 例句

1. I need to confirm whether we can get a table for eight.
   - 我得确认一下能不能订到八人桌。

2. I need to confirm whether we can bring our own drinks.
   - 我得确认一下能不能自带饮料。

3. I need to confirm whether we can park there for free.
   - 我得确认一下那里能不能免费停车。

4. I need to confirm whether we can push the time to seven.
   - 我得确认一下时间能不能改到七点。

5. I need to confirm whether we can use the rooftop area.
   - 我得确认一下能不能用那个天台。
