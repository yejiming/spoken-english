# 252-last-minute-plan Last Minute Plan

- 场景: Social Plans / 社交安排
- 句型: This is last minute, but wanna ...?
- 意思: 临时起意
- 用法: 用于临时发起一个邀请。

## 例句

1. This is last minute, but wanna get sushi?
   - 临时起意，想去吃寿司吗？

2. This is last minute, but wanna catch a movie?
   - 临时起意，想去看电影吗？

3. This is last minute, but wanna hit the pool?
   - 临时起意，想去游泳吗？

4. This is last minute, but wanna come over?
   - 临时起意，想来我家坐坐吗？

5. This is last minute, but wanna grab froyo?
   - 临时起意，想去吃冻酸奶吗？
