# 086-binge-watching Binge Watching

- 场景: Daily Life / 日常生活
- 句型: I've been binge-watching ...
- 意思: 一直在追剧
- 用法: 用于表示你连续不断地在看某部剧或节目。

## 例句

1. I've been binge-watching that new crime series.
   - 我一直在追那部新犯罪剧。

2. I've been binge-watching cooking shows.
   - 我一直在看烹饪节目。

3. I've been binge-watching a Korean drama.
   - 我一直在追一部韩剧。

4. I've been binge-watching reality TV.
   - 我一直在看真人秀。

5. I've been binge-watching old sitcoms.
   - 我一直在重温老情景喜剧。
