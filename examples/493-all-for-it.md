# 493-all-for-it All For It

- 场景: Feelings & Opinions / 感受观点
- 句型: I'm all for ...
- 意思: 完全赞成
- 用法: 用于说非常赞同某个想法或建议。

## 例句

1. I'm all for trying new restaurants every weekend.
   - 每周末试新餐厅我完全赞成。

2. I'm all for taking breaks when you need them.
   - 需要休息就休息我完全赞成。

3. I'm all for spending more time outdoors.
   - 多花时间在户外我完全赞成。

4. I'm all for learning something new every month.
   - 每个月学点新东西我完全赞成。

5. I'm all for having honest conversations.
   - 坦诚交流我完全赞成。
