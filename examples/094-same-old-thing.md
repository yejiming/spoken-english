# 094-same-old-thing Same Old Thing

- 场景: Daily Life / 日常生活
- 句型: I did the same old ...
- 意思: 又是老一套
- 用法: 用于描述做了跟平时一样的事情，毫无新意。

## 例句

1. I did the same old morning routine.
   - 我又走了一遍老一套的早间流程。

2. I did the same old grocery run.
   - 我又去买了一样的菜。

3. I did the same old workout.
   - 我又做了同样的运动。

4. I did the same old commute.
   - 我又走了同样的通勤路线。

5. I did the same old dinner prep.
   - 我又做了一样的晚饭准备。
