# 246-catching-up-with Catching Up With

- 场景: Social Plans / 社交安排
- 句型: I'm catching up with ... this weekend.
- 意思: 周末叙旧
- 用法: 用于告诉别人周末要跟某人聚一聚。

## 例句

1. I'm catching up with Jenny this weekend.
   - 我这周末要和珍妮聚一聚。

2. I'm catching up with my old roommate this weekend.
   - 我这周末要见见以前的室友。

3. I'm catching up with a college buddy this weekend.
   - 我这周末要见个大学同学。

4. I'm catching up with my mentor this weekend.
   - 我这周末要和导师聊聊。

5. I'm catching up with the team this weekend.
   - 我这周末要和团队聚聚。
