# 037-almost-done Almost Done

- 场景: Daily Life / 日常生活
- 句型: I'm almost done with ...
- 意思: 快要做完了
- 用法: 用于告诉别人你正在做的事快要完成了。

## 例句

1. I'm almost done with the dishes.
   - 我碗快洗完了。

2. I'm almost done with folding the clothes.
   - 我衣服快叠完了。

3. I'm almost done with cooking.
   - 我饭快做好了。

4. I'm almost done with mopping the floor.
   - 我地快拖完了。

5. I'm almost done with packing.
   - 我行李快收完了。
