# 159-picking-up-where Picking Up Where

- 场景: Work & School / 工作学习
- 句型: I'm picking up where I left off with ...
- 意思: 接着上次继续
- 用法: 用于说你从上次中断的地方继续某件事。

## 例句

1. I'm picking up where I left off with the research.
   - 我接着上次的地方继续做研究。

2. I'm picking up where I left off with chapter three.
   - 我接着上次的地方继续写第三章。

3. I'm picking up where I left off with the code refactor.
   - 我接着上次的地方继续重构代码。

4. I'm picking up where I left off with the client proposal.
   - 我接着上次的地方继续写客户提案。

5. I'm picking up where I left off with the inventory.
   - 我接着上次的地方继续盘库存。
