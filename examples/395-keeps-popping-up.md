# 395-keeps-popping-up Keeps Popping Up

- 场景: Problems & Solutions / 问题处理
- 句型: This error keeps popping up when I ...
- 意思: 错误老是弹出来
- 用法: 用于说某个错误反复出现。

## 例句

1. This error keeps popping up when I open the app.
   - 我一打开应用这个错误就弹出来。

2. This error keeps popping up when I try to save.
   - 我一保存这个错误就弹出来。

3. This error keeps popping up when I click submit.
   - 我一点提交这个错误就弹出来。

4. This error keeps popping up when I switch tabs.
   - 我一切换标签页这个错误就弹出来。

5. This error keeps popping up when I connect the device.
   - 我一连设备这个错误就弹出来。
