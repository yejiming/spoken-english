# 367-going-in-circles Going In Circles

- 场景: Problems & Solutions / 问题处理
- 句型: I feel like I'm going in circles with ...
- 意思: 原地打转
- 用法: 用于说反复尝试却回到原点。

## 例句

1. I feel like I'm going in circles with this bug.
   - 我觉得我修这个bug一直在原地打转。

2. I feel like I'm going in circles with customer service.
   - 我觉得跟客服沟通一直在原地打转。

3. I feel like I'm going in circles with this essay.
   - 我觉得写这篇文章一直在原地打转。

4. I feel like I'm going in circles with the negotiations.
   - 我觉得谈判一直在原地打转。

5. I feel like I'm going in circles with this diet plan.
   - 我觉得我的减肥计划一直在原地打转。
