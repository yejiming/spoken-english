# 31-get-this-done Get This Done

- 场景: Work & School / 工作学习
- 句型: I need to get this ...
- 意思: 把事情处理完。
- 用法: 用于说要把事情做完。

## 例句

1. I need to get this the deadline
   - 我得把这个截止时间弄好。

2. I need to get this my files
   - 我得把这个我的文件弄好。

3. I need to get this the typo
   - 我得把这个这个错字弄好。

4. I need to get this class prep
   - 我得把这个备课弄好。

5. I need to get this the comments
   - 我得把这个这些批注弄好。
