# 014-still-trying Still Trying

- 场景: Daily Life / 日常生活
- 句型: I'm still trying to ...
- 意思: 还在适应或练习
- 用法: 用于说你还没完全搞定。

## 例句

1. I'm still trying to wake up earlier.
   - 我还在努力早起。

2. I'm still trying to cut back on coffee.
   - 我还在努力少喝咖啡。

3. I'm still trying to learn how to cook.
   - 我还在努力学做饭。

4. I'm still trying to stick to a budget.
   - 我还在努力控制开销。

5. I'm still trying to quit staying up late.
   - 我还在努力改掉熬夜的习惯。
