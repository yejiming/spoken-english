# 026-don-t-feel-like Don't Feel Like

- 场景: Daily Life / 日常生活
- 句型: I don't feel like ...ing today.
- 意思: 今天不想做某事
- 用法: 用于表达今天没有心情或意愿去做某件事。

## 例句

1. I don't feel like cooking today.
   - 我今天不想做饭。

2. I don't feel like going out today.
   - 我今天不想出门。

3. I don't feel like exercising today.
   - 我今天不想锻炼。

4. I don't feel like cleaning today.
   - 我今天不想打扫卫生。

5. I don't feel like dealing with that today.
   - 我今天不想处理那件事。
