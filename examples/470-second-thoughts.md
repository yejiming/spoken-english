# 470-second-thoughts Second Thoughts

- 场景: Feelings & Opinions / 感受观点
- 句型: I'm having second thoughts about ...
- 意思: 开始犹豫了
- 用法: 用于说对之前的决定产生怀疑。

## 例句

1. I'm having second thoughts about the new apartment.
   - 对新公寓我开始犹豫了。

2. I'm having second thoughts about the color I picked.
   - 对我选的颜色我开始犹豫了。

3. I'm having second thoughts about accepting the offer.
   - 对接受那个邀请我开始犹豫了。

4. I'm having second thoughts about the vacation plan.
   - 对度假计划我开始犹豫了。

5. I'm having second thoughts about cutting my hair.
   - 对剪头发我开始犹豫了。
