# 087-out-the-door Out The Door

- 场景: Daily Life / 日常生活
- 句型: I'm usually out the door by ...
- 意思: 通常几点出门
- 用法: 用于描述你平时几点出门的习惯。

## 例句

1. I'm usually out the door by seven thirty.
   - 我通常七点半出门。

2. I'm usually out the door by eight.
   - 我通常八点出门。

3. I'm usually out the door by six forty-five.
   - 我通常六点四十五出门。

4. I'm usually out the door by nine on weekends.
   - 我周末通常九点出门。

5. I'm usually out the door by seven on weekdays.
   - 我工作日通常七点出门。
