# 37-setting-up Setting Up

- 场景: Work & School / 工作学习
- 句型: I'm setting up ... now.
- 意思: 正在搭建安排。
- 用法: 用于说你在设置流程。

## 例句

1. I'm setting up the call setup now.
   - 我现在在安排电话会议安排。

2. I'm setting up the client follow-up now.
   - 我现在在安排客户跟进。

3. I'm setting up the deadline now.
   - 我现在在安排截止时间。

4. I'm setting up my files now.
   - 我现在在安排我的文件。

5. I'm setting up the typo now.
   - 我现在在安排这个错字。
