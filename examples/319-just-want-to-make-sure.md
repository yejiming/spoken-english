# 319-just-want-to-make-sure Just Want To Make Sure

- 场景: Problems & Solutions / 问题处理
- 句型: I just want to make sure ...
- 意思: 只想确认一下
- 用法: 用于表达你想再确认某件事没有问题。

## 例句

1. I just want to make sure everything is backed up before the update.
   - 我只是想确认更新前都备份好了。

2. I just want to make sure the fix actually solved the problem.
   - 我只是想确认修复确实解决了问题。

3. I just want to make sure my files didn't get corrupted.
   - 我只是想确认我的文件没有损坏。

4. I just want to make sure the refund goes through.
   - 我只是想确认退款能到账。

5. I just want to make sure I'm not voiding the warranty.
   - 我只是想确认不会因此失去保修。
