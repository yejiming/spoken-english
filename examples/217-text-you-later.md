# 217-text-you-later Text You Later

- 场景: Social Plans / 社交安排
- 句型: I'll text you when I'm done with ...
- 意思: 做完就联系你
- 用法: 用于告诉对方你忙完某件事后会发消息。

## 例句

1. I'll text you when I'm done with my workout.
   - 我健身完就给你发消息。

2. I'll text you when I'm done with this meeting.
   - 我开完会就给你发消息。

3. I'll text you when I'm done with dinner.
   - 我吃完饭就给你发消息。

4. I'll text you when I'm done with the grocery run.
   - 我买完菜就给你发消息。

5. I'll text you when I'm done with my shift.
   - 我下了班就给你发消息。
