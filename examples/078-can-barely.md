# 078-can-barely Can Barely

- 场景: Daily Life / 日常生活
- 句型: I can barely ... this early.
- 意思: 这么早根本做不了
- 用法: 用于表达一大早还没完全清醒，很难做某件事。

## 例句

1. I can barely keep my eyes open this early.
   - 这么早我眼睛都睁不开。

2. I can barely think straight this early.
   - 这么早我脑子都转不过来。

3. I can barely talk this early.
   - 这么早我话都说不利索。

4. I can barely function this early.
   - 这么早我根本没法正常运转。

5. I can barely make decisions this early.
   - 这么早我根本做不了决定。
