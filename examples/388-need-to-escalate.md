# 388-need-to-escalate Need To Escalate

- 场景: Problems & Solutions / 问题处理
- 句型: I need to escalate ... to someone.
- 意思: 需要找人升级处理
- 用法: 用于说需要把问题提交给更高层。

## 例句

1. I need to escalate this ticket to a manager.
   - 我需要把这个工单升级给经理。

2. I need to escalate the complaint to headquarters.
   - 我需要把投诉升级到总部。

3. I need to escalate the security issue to the IT team.
   - 我需要把安全问题升级给IT团队。

4. I need to escalate this billing dispute to a supervisor.
   - 我需要把计费纠纷升级给主管。

5. I need to escalate the outage report to engineering.
   - 我需要把故障报告升级给工程团队。
