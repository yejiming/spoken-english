# 177-tying-up Tying Up

- 场景: Work & School / 工作学习
- 句型: I'm tying up ... before the weekend.
- 意思: 周末前收尾
- 用法: 用于说你在周末之前把某些事收个尾。

## 例句

1. I'm tying up loose ends before the weekend.
   - 我在周末前把零散的事收个尾。

2. I'm tying up the project documentation before the weekend.
   - 我在周末前把项目文档收个尾。

3. I'm tying up the invoice approvals before the weekend.
   - 我在周末前把发票审批收个尾。

4. I'm tying up my lab work before the weekend.
   - 我在周末前把实验收个尾。

5. I'm tying up the final edits before the weekend.
   - 我在周末前把最后的修改收个尾。
