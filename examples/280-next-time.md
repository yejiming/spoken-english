# 280-next-time Next Time

- 场景: Social Plans / 社交安排
- 句型: Next time let's try ...
- 意思: 下次试试
- 用法: 用于提议下次聚会尝试新的东西。

## 例句

1. Next time let's try that ramen shop.
   - 下次咱们试试那家拉面店。

2. Next time let's try going earlier.
   - 下次咱们试试早点去。

3. Next time let's try a different route.
   - 下次咱们试试走另一条路。

4. Next time let's try cooking together.
   - 下次咱们试试一起做饭。

5. Next time let's try the outdoor seating.
   - 下次咱们试试坐外面。
