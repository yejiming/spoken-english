# 385-keeps-timing-out Keeps Timing Out

- 场景: Problems & Solutions / 问题处理
- 句型: It keeps timing out when I ...
- 意思: 老是超时
- 用法: 用于说操作反复超时。

## 例句

1. It keeps timing out when I try to upload the file.
   - 我上传文件时老是超时。

2. It keeps timing out when I try to connect to the server.
   - 我连接服务器时老是超时。

3. It keeps timing out when I try to sync my data.
   - 我同步数据时老是超时。

4. It keeps timing out when I try to run the report.
   - 我跑报表时老是超时。

5. It keeps timing out when I try to download the update.
   - 我下载更新时老是超时。
