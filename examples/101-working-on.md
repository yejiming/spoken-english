# 101-working-on Working On

- 场景: Work & School / 工作学习
- 句型: I'm working on ... right now.
- 意思: 正在忙某件事
- 用法: 用于告诉别人你此刻正在做什么。

## 例句

1. I'm working on the quarterly report right now.
   - 我现在正在写季度报告。

2. I'm working on a new marketing plan right now.
   - 我现在正在做一个新的营销方案。

3. I'm working on my thesis outline right now.
   - 我现在正在弄论文大纲。

4. I'm working on the budget spreadsheet right now.
   - 我现在正在做预算表。

5. I'm working on the slides for tomorrow's presentation right now.
   - 我现在正在做明天演示用的幻灯片。
