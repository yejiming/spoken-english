# 09-in-a-bit In A Bit

- 场景: Daily Life / 日常生活
- 句型: I'm going to ... in a bit.
- 意思: 稍后就要做。
- 用法: 用于说自己等会儿要去做什么。

## 例句

1. I'm going to pack my bag in a bit.
   - 我过一会儿要收拾书包。

2. I'm going to do a quick stretch in a bit.
   - 我过一会儿要简单拉伸一下。

3. I'm going to water the plants in a bit.
   - 我过一会儿要给植物浇水。

4. I'm going to tidy up the kitchen in a bit.
   - 我过一会儿要收拾厨房。

5. I'm going to grab breakfast in a bit.
   - 我过一会儿要吃早餐。
