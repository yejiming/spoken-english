# 295-checking-schedules Checking Schedules

- 场景: Social Plans / 社交安排
- 句型: I'm checking if ... works for everyone.
- 意思: 看大家有没有空
- 用法: 用于表示你在确认某个时间是否所有人都方便。

## 例句

1. I'm checking if Saturday works for everyone.
   - 我在看周六大家有没有空。

2. I'm checking if next Friday works for everyone.
   - 我在看下周五大家行不行。

3. I'm checking if noon works for everyone.
   - 我在看中午大家有没有空。

4. I'm checking if the 15th works for everyone.
   - 我在看十五号大家行不行。

5. I'm checking if Sunday brunch works for everyone.
   - 我在看周日早午餐大家方不方便。
