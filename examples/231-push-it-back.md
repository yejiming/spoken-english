# 231-push-it-back Push It Back

- 场景: Social Plans / 社交安排
- 句型: Can we push ... back a bit?
- 意思: 往后推一下
- 用法: 用于请求把约定时间推迟一些。

## 例句

1. Can we push dinner back a bit?
   - 晚饭能往后推一推吗？

2. Can we push the meeting back a bit?
   - 碰面能晚一点吗？

3. Can we push our hangout back a bit?
   - 我们的聚会能推迟一点吗？

4. Can we push the call back a bit?
   - 电话能晚一点打吗？

5. Can we push kickoff back a bit?
   - 开始时间能推迟一下吗？
