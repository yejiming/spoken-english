# 271-invite-them-too Invite Them Too

- 场景: Social Plans / 社交安排
- 句型: Should we invite ... too?
- 意思: 要叫上他们吗
- 用法: 用于询问是否应该邀请更多的人。

## 例句

1. Should we invite Kevin too?
   - 要不要也叫上凯文？

2. Should we invite the new guy too?
   - 要不要也叫上新来的？

3. Should we invite your roommate too?
   - 要不要也叫上你室友？

4. Should we invite the neighbors too?
   - 要不要也叫上邻居？

5. Should we invite the whole group too?
   - 要不要把所有人都叫上？
