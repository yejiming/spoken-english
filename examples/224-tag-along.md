# 224-tag-along Tag Along

- 场景: Social Plans / 社交安排
- 句型: Mind if I tag along to ...?
- 意思: 能否一起去
- 用法: 用于礼貌地询问是否可以跟别人一起去。

## 例句

1. Mind if I tag along to the concert?
   - 我能跟你们一起去演唱会吗？

2. Mind if I tag along to the mall?
   - 我能跟着一起去商场吗？

3. Mind if I tag along to brunch?
   - 我能一起去吃早午餐吗？

4. Mind if I tag along to the gym?
   - 我能跟你一起去健身房吗？

5. Mind if I tag along to the bar?
   - 我能一起去酒吧吗？
