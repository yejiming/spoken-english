# 372-already-tried Already Tried

- 场景: Problems & Solutions / 问题处理
- 句型: I already tried ... and it didn't help.
- 意思: 试过了没用
- 用法: 用于说已经尝试过某个方法但没效果。

## 例句

1. I already tried turning it off and on and it didn't help.
   - 我已经试过关机重启了但没用。

2. I already tried resetting the router and it didn't help.
   - 我已经试过重置路由器了但没用。

3. I already tried switching browsers and it didn't help.
   - 我已经试过换浏览器了但没用。

4. I already tried deleting the app and it didn't help.
   - 我已经试过删掉应用了但没用。

5. I already tried using a different cable and it didn't help.
   - 我已经试过换线了但没用。
