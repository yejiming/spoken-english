# 183-brushing-up Brushing Up

- 场景: Work & School / 工作学习
- 句型: I'm brushing up on ...
- 意思: 在温习复习
- 用法: 用于说你在重新学习或复习以前学过的东西。

## 例句

1. I'm brushing up on my Excel skills.
   - 我在温习Excel技能。

2. I'm brushing up on statistics before the exam.
   - 我在考试前温习统计学。

3. I'm brushing up on company policies.
   - 我在复习公司政策。

4. I'm brushing up on my Python for the new project.
   - 我在为新项目复习Python。

5. I'm brushing up on presentation techniques.
   - 我在复习演讲技巧。
