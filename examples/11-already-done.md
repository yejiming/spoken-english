# 11-already-done Already Done

- 场景: Daily Life / 日常生活
- 句型: I've already ...
- 意思: 已经完成了。
- 用法: 用于说明事情已经做完。

## 例句

1. I've already call my parents
   - 我已经给父母打电话了。

2. I've already pay a few bills
   - 我已经付几笔账单了。

3. I've already take out the trash
   - 我已经倒垃圾了。

4. I've already open the windows
   - 我已经打开窗户了。

5. I've already turn on some music
   - 我已经放点音乐了。
