# 368-narrowing-down Narrowing Down

- 场景: Problems & Solutions / 问题处理
- 句型: I'm narrowing down what's wrong with ...
- 意思: 在排查原因
- 用法: 用于说正在缩小问题范围。

## 例句

1. I'm narrowing down what's wrong with the engine.
   - 我在排查发动机哪里出了问题。

2. I'm narrowing down what's wrong with the network.
   - 我在排查网络问题的原因。

3. I'm narrowing down what's wrong with the formula.
   - 我在排查公式哪里出了错。

4. I'm narrowing down what's wrong with the heater.
   - 我在排查暖气出了什么问题。

5. I'm narrowing down what's wrong with the pipeline.
   - 我在排查流水线哪里出了问题。
