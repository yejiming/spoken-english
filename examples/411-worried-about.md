# 411-worried-about Worried About

- 场景: Feelings & Opinions / 感受观点
- 句型: I'm worried about ...
- 意思: 有些担心
- 用法: 用于表达对某件事的忧虑。

## 例句

1. I'm worried about the deadline for this project.
   - 我担心这个项目的截止日期。

2. I'm worried about my parents living alone.
   - 我担心父母独自生活。

3. I'm worried about the weather for our outdoor event.
   - 我担心我们户外活动那天的天气。

4. I'm worried about making the wrong decision.
   - 我担心做出错误的决定。

5. I'm worried about how the team will handle the changes.
   - 我担心团队怎么应对这些变化。
