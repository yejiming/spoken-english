# 63-messed-up Messed Up

- 场景: Problems & Solutions / 问题处理
- 句型: I think I messed up ...
- 意思: 承认失误。
- 用法: 用于说自己可能弄错了。

## 例句

1. I think I messed up get the video to play
   - 我觉得我把让视频播放搞砸了。

2. I think I messed up reset the password
   - 我觉得我把重设密码搞砸了。

3. I think I messed up finish the upload
   - 我觉得我把完成上传搞砸了。

4. I think I messed up charge the laptop
   - 我觉得我把给笔记本充电搞砸了。

5. I think I messed up fix the microphone
   - 我觉得我把修好麦克风搞砸了。
