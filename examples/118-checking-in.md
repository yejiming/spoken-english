# 118-checking-in Checking In

- 场景: Work & School / 工作学习
- 句型: I'm checking in on ...
- 意思: 过来看看进展
- 用法: 用于说你来了解某件事的最新状况。

## 例句

1. I'm checking in on the project status.
   - 我来看看项目进展。

2. I'm checking in on how the new intern is doing.
   - 我来看看新实习生干得怎么样。

3. I'm checking in on the order we placed last week.
   - 我来跟进一下上周下的订单。

4. I'm checking in on the server migration progress.
   - 我来看看服务器迁移的进展。

5. I'm checking in on the students' group work.
   - 我来看看学生们小组作业的情况。
