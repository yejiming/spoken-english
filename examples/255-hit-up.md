# 255-hit-up Hit Up

- 场景: Social Plans / 社交安排
- 句型: Let's hit up ... this weekend.
- 意思: 周末去
- 用法: 用于提议周末一起去某个地方玩。

## 例句

1. Let's hit up that new Thai place this weekend.
   - 周末去那家新泰国餐厅吧。

2. Let's hit up the flea market this weekend.
   - 周末去跳蚤市场吧。

3. Let's hit up the rooftop bar this weekend.
   - 周末去天台酒吧吧。

4. Let's hit up the hiking trail this weekend.
   - 周末去那条步道吧。

5. Let's hit up the bowling alley this weekend.
   - 周末去打保龄球吧。
