# 021-running-late Running Late

- 场景: Daily Life / 日常生活
- 句型: I'm running late for ...
- 意思: 快要迟到了
- 用法: 用于告诉别人你来不及准时到达某处。

## 例句

1. I'm running late for work again.
   - 我上班又要迟到了。

2. I'm running late for my dentist appointment.
   - 我看牙医的预约要迟到了。

3. I'm running late for the morning meeting.
   - 我早会要迟到了。

4. I'm running late for picking up the kids.
   - 我接孩子要来不及了。

5. I'm running late for dinner with my parents.
   - 我跟爸妈吃饭要迟到了。
