# 386-misunderstood Misunderstood

- 场景: Problems & Solutions / 问题处理
- 句型: I misunderstood how to ...
- 意思: 理解错了
- 用法: 用于说误解了做法或步骤。

## 例句

1. I misunderstood how to set up the two-factor auth.
   - 我理解错了怎么设置双重验证。

2. I misunderstood how to file the expense report.
   - 我理解错了怎么报销。

3. I misunderstood how to configure the network.
   - 我理解错了怎么配置网络。

4. I misunderstood how to use the new scheduling tool.
   - 我理解错了怎么用新的排班工具。

5. I misunderstood how to assemble the furniture.
   - 我理解错了怎么组装家具。
