# 156-juggling Juggling

- 场景: Work & School / 工作学习
- 句型: I'm juggling ... at the same time.
- 意思: 同时兼顾多个
- 用法: 用于说你在同时处理好几件事。

## 例句

1. I'm juggling three projects at the same time.
   - 我在同时兼顾三个项目。

2. I'm juggling work and school at the same time.
   - 我在同时兼顾工作和学业。

3. I'm juggling two jobs at the same time.
   - 我在同时做两份工作。

4. I'm juggling five different tasks at the same time.
   - 我在同时处理五个不同的任务。

5. I'm juggling client meetings and deadlines at the same time.
   - 我在同时兼顾客户会议和截止日期。
