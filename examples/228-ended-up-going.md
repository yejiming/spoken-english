# 228-ended-up-going Ended Up Going

- 场景: Social Plans / 社交安排
- 句型: We ended up going to ...
- 意思: 最终去了
- 用法: 用于描述最终选择去了哪里。

## 例句

1. We ended up going to that new ramen place.
   - 我们最后去了那家新开的拉面馆。

2. We ended up going to the rooftop bar.
   - 我们最后去了那个天台酒吧。

3. We ended up going to Dave's place.
   - 我们最后去了戴夫家。

4. We ended up going to a karaoke spot.
   - 我们最后去唱了卡拉OK。

5. We ended up going to the lake instead.
   - 我们最后改去了湖边。
