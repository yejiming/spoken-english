# 152-drafted-up Drafted Up

- 场景: Work & School / 工作学习
- 句型: I drafted up ... yesterday.
- 意思: 昨天起草了
- 用法: 用于说你昨天拟了一份初稿。

## 例句

1. I drafted up the project plan yesterday.
   - 我昨天起草了项目计划。

2. I drafted up a proposal for the new feature yesterday.
   - 我昨天起草了新功能的提案。

3. I drafted up the meeting agenda yesterday.
   - 我昨天起草了会议议程。

4. I drafted up an outline for the essay yesterday.
   - 我昨天起草了论文的大纲。

5. I drafted up the budget request yesterday.
   - 我昨天起草了预算申请。
