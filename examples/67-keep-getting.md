# 67-keep-getting Keep Getting

- 场景: Problems & Solutions / 问题处理
- 句型: I keep getting an error when I ...
- 意思: 反复出错。
- 用法: 用于说总是遇到同样问题。

## 例句

1. I keep getting an error when I lose the progress
   - 每次我丢掉进度的时候都会报错。

2. I keep getting an error when I get this sorted out
   - 每次我把这件事处理好的时候都会报错。

3. I keep getting an error when I open the app
   - 每次我打开应用的时候都会报错。

4. I keep getting an error when I log in
   - 每次我登录的时候都会报错。

5. I keep getting an error when I send the file
   - 每次我发送文件的时候都会报错。
