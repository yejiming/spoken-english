# 57-text-you-later Text You Later

- 场景: Social Plans / 社交安排
- 句型: I'll text you when I'm done with ...
- 意思: 做完再联系。
- 用法: 用于说结束后再通知。

## 例句

1. I'll text you when I'm done with stop by later
   - 我待会儿顺路过去做完后会发你消息。

2. I'll text you when I'm done with pick you up
   - 我接你做完后会发你消息。

3. I'll text you when I'm done with swing by the cafe
   - 我顺路去咖啡馆做完后会发你消息。

4. I'll text you when I'm done with make a reservation
   - 我订座位做完后会发你消息。

5. I'll text you when I'm done with bring something to share
   - 我带点吃的分享做完后会发你消息。
