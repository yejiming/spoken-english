# 283-been-a-while Been A While

- 场景: Social Plans / 社交安排
- 句型: It's been a while since we ...
- 意思: 好久没一起了
- 用法: 用于感叹很久没有一起做某件事了。

## 例句

1. It's been a while since we hung out.
   - 咱们好久没一起出来玩了。

2. It's been a while since we grabbed drinks.
   - 咱们好久没一起喝过了。

3. It's been a while since we went hiking.
   - 咱们好久没去爬山了。

4. It's been a while since we cooked together.
   - 咱们好久没一起做饭了。

5. It's been a while since we had a proper dinner.
   - 咱们好久没好好吃顿饭了。
