# 266-plans-are-set Plans Are Set

- 场景: Social Plans / 社交安排
- 句型: I've got plans locked in for ...
- 意思: 安排已确定
- 用法: 用于表示某项安排已经确认不会再变。

## 例句

1. I've got plans locked in for Saturday night.
   - 周六晚上的安排已经定了。

2. I've got plans locked in for the holiday.
   - 假期的安排已经定了。

3. I've got plans locked in for my birthday.
   - 我生日的安排已经定了。

4. I've got plans locked in for New Year's.
   - 新年的安排已经定了。

5. I've got plans locked in for this weekend.
   - 这个周末的安排已经定了。
