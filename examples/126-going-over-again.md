# 126-going-over-again Going Over Again

- 场景: Work & School / 工作学习
- 句型: I'm going over ... one more time.
- 意思: 再过一遍
- 用法: 用于说你要再复习或检查某样东西。

## 例句

1. I'm going over my presentation one more time.
   - 我要再过一遍我的演示稿。

2. I'm going over the contract one more time.
   - 我要再看一遍合同。

3. I'm going over my notes one more time.
   - 我要再过一遍笔记。

4. I'm going over the test answers one more time.
   - 我要再检查一遍考试答案。

5. I'm going over the proposal one more time.
   - 我要再看一遍提案。
