# 250-double-booked Double Booked

- 场景: Social Plans / 社交安排
- 句型: I'm double-booked for ...
- 意思: 时间冲突了
- 用法: 用于说明你同一个时段有两个安排。

## 例句

1. I'm double-booked for Saturday afternoon.
   - 我周六下午有两个安排撞了。

2. I'm double-booked for the holiday weekend.
   - 假期周末我有两个局撞了。

3. I'm double-booked for Friday night.
   - 我周五晚上时间冲突了。

4. I'm double-booked for the 4th.
   - 我四号有两件事撞了。

5. I'm double-booked for tomorrow evening.
   - 我明天晚上时间冲突了。
