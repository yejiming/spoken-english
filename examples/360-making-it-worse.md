# 360-making-it-worse Making It Worse

- 场景: Problems & Solutions / 问题处理
- 句型: I think I'm making ... worse.
- 意思: 越弄越糟
- 用法: 用于说自己的操作可能在帮倒忙。

## 例句

1. I think I'm making the stain worse by scrubbing it.
   - 我越擦这个污渍越严重了。

2. I think I'm making the code worse with every edit.
   - 我每改一次代码感觉越来越糟。

3. I think I'm making the situation worse by arguing.
   - 我越争论情况越糟。

4. I think I'm making the dent worse by trying to fix it.
   - 我越修这个凹痕越严重了。

5. I think I'm making the lag worse by installing stuff.
   - 我越装东西延迟越严重了。
