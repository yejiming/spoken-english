# 475-can-live-with Can Live With

- 场景: Feelings & Opinions / 感受观点
- 句型: I can live with ...
- 意思: 能接受
- 用法: 用于说虽然不完美但可以接受。

## 例句

1. I can live with a smaller apartment if the location is good.
   - 地段好的话小一点的公寓我能接受。

2. I can live with a few scratches on the phone.
   - 手机上几个划痕我能接受。

3. I can live with the longer commute for the better job.
   - 为了更好的工作通勤长一点我能接受。

4. I can live with not having the latest gadgets.
   - 没有最新的数码产品我能接受。

5. I can live with the design even if it's not perfect.
   - 设计不完美我也能接受。
