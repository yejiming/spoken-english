# 392-drained-from Drained From

- 场景: Problems & Solutions / 问题处理
- 句型: I'm drained from dealing with ...
- 意思: 处理得精疲力尽
- 用法: 用于说反复处理问题感到疲惫。

## 例句

1. I'm drained from dealing with the insurance claim.
   - 处理保险理赔把我累垮了。

2. I'm drained from dealing with the tech issues all day.
   - 一整天处理技术问题把我累垮了。

3. I'm drained from dealing with back-to-back meetings.
   - 连续开会把我累垮了。

4. I'm drained from dealing with the customer complaints.
   - 处理客户投诉把我累垮了。

5. I'm drained from dealing with the move this week.
   - 这周忙搬家把我累垮了。
