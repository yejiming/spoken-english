# 268-up-for-it Up For It

- 场景: Social Plans / 社交安排
- 句型: Are you up for ...?
- 意思: 想不想去
- 用法: 用于询问对方是否有兴趣参加某事。

## 例句

1. Are you up for a hike tomorrow?
   - 明天想去爬山吗？

2. Are you up for some mini golf?
   - 想去打迷你高尔夫吗？

3. Are you up for a late-night drive?
   - 想去兜兜风吗？

4. Are you up for trying that new cafe?
   - 想去试试那家新咖啡馆吗？

5. Are you up for a board game marathon?
   - 想来个桌游马拉松吗？
