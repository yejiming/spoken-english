# 303-messed-up Messed Up

- 场景: Problems & Solutions / 问题处理
- 句型: I think I messed up ...
- 意思: 觉得自己搞砸
- 用法: 用于承认你可能把某件事弄错了。

## 例句

1. I think I messed up the formatting on this document.
   - 我觉得我把这份文件的格式搞乱了。

2. I think I messed up the settings on my phone.
   - 我觉得我把手机设置搞乱了。

3. I think I messed up the wiring when I moved the desk.
   - 我觉得搬桌子的时候把线弄乱了。

4. I think I messed up the order — I got the wrong parts.
   - 我觉得订单搞错了，收到了错的零件。

5. I think I messed up the installation steps.
   - 我觉得我把安装步骤搞错了。
