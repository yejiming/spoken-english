# 060-done-for-the-day Done For The Day

- 场景: Daily Life / 日常生活
- 句型: I'm done with ... for the day.
- 意思: 今天到此为止
- 用法: 用于宣布今天某件事你不打算再继续做了。

## 例句

1. I'm done with chores for the day.
   - 我今天家务就做到这了。

2. I'm done with cooking for the day.
   - 我今天做饭就到这了。

3. I'm done with studying for the day.
   - 我今天学习就到这了。

4. I'm done with errands for the day.
   - 我今天跑腿就到这了。

5. I'm done with exercising for the day.
   - 我今天锻炼就到这了。
