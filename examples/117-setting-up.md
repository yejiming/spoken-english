# 117-setting-up Setting Up

- 场景: Work & School / 工作学习
- 句型: I'm setting up ... now.
- 意思: 正在搭建/安排
- 用法: 用于说你正在准备或配置某样东西。

## 例句

1. I'm setting up the new development environment now.
   - 我正在搭建新的开发环境。

2. I'm setting up the conference call now.
   - 我正在安排电话会议。

3. I'm setting up a shared folder for the team now.
   - 我正在给团队建一个共享文件夹。

4. I'm setting up the lab equipment now.
   - 我正在准备实验设备。

5. I'm setting up the onboarding process for the new hire now.
   - 我正在安排新员工的入职流程。
