# 236-running-behind Running Behind

- 场景: Social Plans / 社交安排
- 句型: I'm running behind — can we ...?
- 意思: 来不及了
- 用法: 用于告知对方自己落后于计划，请求调整。

## 例句

1. I'm running behind — can we meet at eight instead?
   - 我来不及了——能改成八点见吗？

2. I'm running behind — can we push it fifteen minutes?
   - 我晚了——能推迟十五分钟吗？

3. I'm running behind — can we just meet there?
   - 我来不及了——咱们直接在那碰面行吗？

4. I'm running behind — can we skip appetizers?
   - 我迟了——咱们别点前菜了行吗？

5. I'm running behind — can we do a later showing?
   - 我来不及了——能看晚一场吗？
