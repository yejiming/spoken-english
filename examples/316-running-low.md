# 316-running-low Running Low

- 场景: Problems & Solutions / 问题处理
- 句型: I'm running low on ...
- 意思: 快要用完了
- 用法: 用于表达某种资源即将耗尽。

## 例句

1. I'm running low on battery — do you have a charger?
   - 我手机快没电了，你有充电器吗？

2. I'm running low on storage space on my laptop.
   - 我笔记本的存储空间快用完了。

3. I'm running low on printer ink.
   - 打印机墨水快用完了。

4. I'm running low on time to finish this report.
   - 我快没时间写完这份报告了。

5. I'm running low on data this month.
   - 我这个月的流量快用完了。
