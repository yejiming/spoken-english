# 365-got-flagged Got Flagged

- 场景: Problems & Solutions / 问题处理
- 句型: My ... got flagged for some reason.
- 意思: 莫名被标记了
- 用法: 用于说账号或内容被莫名标记异常。

## 例句

1. My account got flagged for some reason.
   - 我的账号不知为什么被标记了。

2. My payment got flagged for some reason.
   - 我的付款不知为什么被标记了。

3. My post got flagged for some reason.
   - 我的帖子不知为什么被标记了。

4. My transaction got flagged for some reason.
   - 我的交易不知为什么被标记了。

5. My comment got flagged for some reason.
   - 我的评论不知为什么被标记了。
