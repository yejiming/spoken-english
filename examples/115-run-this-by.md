# 115-run-this-by Run This By

- 场景: Work & School / 工作学习
- 句型: I'm running this by ...
- 意思: 找人过目确认
- 用法: 用于说你要把某个方案或想法让某人看一下。

## 例句

1. I'm running this by my manager before we proceed.
   - 我先让经理看一下再继续。

2. I'm running this by the legal team first.
   - 我先让法务团队过目一下。

3. I'm running this by Professor Li for feedback.
   - 我先找李教授看看给点意见。

4. I'm running this by the design lead today.
   - 我今天让设计主管看一下。

5. I'm running this by my co-author before submitting.
   - 我提交前先让合著者过目。
