# 208-let-you-know Let You Know

- 场景: Social Plans / 社交安排
- 句型: I'll let you know if I can ...
- 意思: 确定了就通知
- 用法: 用于告诉对方等你确认后再回复。

## 例句

1. I'll let you know if I can make it to the party.
   - 我能去派对的话就告诉你。

2. I'll let you know if I can get off work early.
   - 我能早下班的话就告诉你。

3. I'll let you know if I can join you guys for dinner.
   - 我能跟你们一起吃饭的话就告诉你。

4. I'll let you know if I can pick you up on the way.
   - 我能顺路接你的话就告诉你。

5. I'll let you know if I can swing by after my meeting.
   - 我开完会能过去的话就告诉你。
