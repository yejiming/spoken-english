# 34-sorting-out Sorting Out

- 场景: Work & School / 工作学习
- 句型: I'm still sorting out ...
- 意思: 还没完全确定。
- 用法: 用于说你在处理复杂情况。

## 例句

1. I'm still sorting out the presentation
   - 我还在理清演示稿。

2. I'm still sorting out finishing this report
   - 我还在理清完成这份报告。

3. I'm still sorting out replying to those emails
   - 我还在理清回复那些邮件。

4. I'm still sorting out the meeting prep
   - 我还在理清会议准备。

5. I'm still sorting out taking notes
   - 我还在理清做笔记。
