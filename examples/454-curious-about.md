# 454-curious-about Curious About

- 场景: Feelings & Opinions / 感受观点
- 句型: I'm curious about ...
- 意思: 很好奇
- 用法: 用于说对某事感到好奇。

## 例句

1. I'm curious about how they make those tiny electronics.
   - 我很好奇他们怎么做出那么小的电子元件。

2. I'm curious about what living abroad is really like.
   - 我很好奇在国外生活到底什么感觉。

3. I'm curious about the story behind that old building.
   - 我很好奇那栋老建筑背后的故事。

4. I'm curious about trying intermittent fasting.
   - 我很好奇间歇性禁食是什么体验。

5. I'm curious about how the algorithm decides what I see.
   - 我很好奇算法怎么决定给我推什么。
