# 91-worried-about Worried About

- 场景: Feelings & Opinions / 感受观点
- 句型: I'm worried about ...
- 意思: 有点担心。
- 用法: 用于表达担忧。

## 例句

1. I'm worried about the new layout
   - 我担心新版布局。

2. I'm worried about getting up early
   - 我担心早起。

3. I'm worried about sharing honest feedback
   - 我担心给出坦诚反馈。

4. I'm worried about waiting too long
   - 我担心等太久。

5. I'm worried about the weather today
   - 我担心今天的天气。
