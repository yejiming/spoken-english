# 090-set-a-reminder Set A Reminder

- 场景: Daily Life / 日常生活
- 句型: I set a reminder to ...
- 意思: 设了提醒
- 用法: 用于告诉别人你设了手机提醒去做某件事。

## 例句

1. I set a reminder to pick up my package.
   - 我设了提醒去取快递。

2. I set a reminder to pay rent.
   - 我设了提醒去交房租。

3. I set a reminder to call the doctor.
   - 我设了提醒去打电话给医生。

4. I set a reminder to take out the trash.
   - 我设了提醒去倒垃圾。

5. I set a reminder to water the plants.
   - 我设了提醒去浇花。
