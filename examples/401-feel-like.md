# 401-feel-like Feel Like

- 场景: Feelings & Opinions / 感受观点
- 句型: I feel like ...
- 意思: 想做某事或主观感觉
- 用法: 用于表达想要做某事或主观直觉。

## 例句

1. I feel like going out for dinner tonight.
   - 我今晚想出去吃饭。

2. I feel like this project is going to be a success.
   - 我觉得这个项目会成功。

3. I feel like taking a long walk after work.
   - 我下班后想去散个步。

4. I feel like something is off about that plan.
   - 我觉得那个方案有点不对劲。

5. I feel like watching a movie this weekend.
   - 我这个周末想看场电影。
