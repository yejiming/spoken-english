# 410-excited-about Excited About

- 场景: Feelings & Opinions / 感受观点
- 句型: I'm excited about ...
- 意思: 非常期待
- 用法: 用于表达对未来某事的兴奋和期待。

## 例句

1. I'm excited about the trip we planned for next month.
   - 我对下个月计划的旅行很期待。

2. I'm excited about starting my new job on Monday.
   - 我对周一开始新工作很期待。

3. I'm excited about the concert this weekend.
   - 我对这个周末的演唱会很兴奋。

4. I'm excited about learning to play the guitar.
   - 我对学吉他很期待。

5. I'm excited about the new season of my favorite show.
   - 我对我最爱的剧的新一季很期待。
