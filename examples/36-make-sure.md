# 36-make-sure Make Sure

- 场景: Work & School / 工作学习
- 句型: I need to make sure I ...
- 意思: 必须确认没问题。
- 用法: 用于强调你要确认。

## 例句

1. I need to make sure I asking for feedback
   - 我得确保我征求反馈。

2. I need to make sure I the spreadsheet
   - 我得确保我这个表格。

3. I need to make sure I the draft
   - 我得确保我草稿。

4. I need to make sure I the call setup
   - 我得确保我电话会议安排。

5. I need to make sure I the client follow-up
   - 我得确保我客户跟进。
