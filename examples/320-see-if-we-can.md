# 320-see-if-we-can See If We Can

- 场景: Problems & Solutions / 问题处理
- 句型: Let's see if we can ...
- 意思: 看看能不能行
- 用法: 用于提议一起尝试解决某个问题。

## 例句

1. Let's see if we can fix it without buying a new one.
   - 看看我们能不能不买新的就修好。

2. Let's see if we can find a workaround for now.
   - 看看我们能不能先找个临时方案。

3. Let's see if we can get a replacement under warranty.
   - 看看能不能在保修期内换一个。

4. Let's see if we can troubleshoot it together.
   - 看看我们能不能一起排查一下。

5. Let's see if we can borrow one from the office.
   - 看看能不能从办公室借一个。
