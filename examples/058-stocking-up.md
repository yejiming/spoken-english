# 058-stocking-up Stocking Up

- 场景: Daily Life / 日常生活
- 句型: I need to stock up on ...
- 意思: 需要囤一些
- 用法: 用于表示需要多买一些常用的东西备着。

## 例句

1. I need to stock up on toilet paper.
   - 我需要囤点卫生纸。

2. I need to stock up on bottled water.
   - 我需要囤点矿泉水。

3. I need to stock up on frozen meals.
   - 我需要囤点冷冻食品。

4. I need to stock up on shampoo.
   - 我需要囤点洗发水。

5. I need to stock up on snacks for the week.
   - 我需要囤点这周吃的零食。
