# 015-gotten-used-to Gotten Used To

- 场景: Daily Life / 日常生活
- 句型: I've gotten used to ...
- 意思: 已经适应了
- 用法: 用于表达适应某种生活方式。

## 例句

1. I've gotten used to waking up at six.
   - 我已经习惯六点起床了。

2. I've gotten used to cooking for myself.
   - 我已经习惯自己做饭了。

3. I've gotten used to taking the subway to work.
   - 我已经习惯坐地铁上班了。

4. I've gotten used to drinking black coffee.
   - 我已经习惯喝黑咖啡了。

5. I've gotten used to living alone.
   - 我已经习惯一个人住了。
