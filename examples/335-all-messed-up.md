# 335-all-messed-up All Messed Up

- 场景: Problems & Solutions / 问题处理
- 句型: My ... is all messed up.
- 意思: 全乱套了
- 用法: 用于说某样东西彻底乱了。

## 例句

1. My schedule is all messed up this week.
   - 我这周的日程全乱套了。

2. My desktop is all messed up after the update.
   - 更新后我的桌面全乱了。

3. My sleep schedule is all messed up.
   - 我的作息全乱套了。

4. My calendar is all messed up with double bookings.
   - 我的日历因为重复预约全乱了。

5. My filing system is all messed up.
   - 我的归档系统全乱套了。
