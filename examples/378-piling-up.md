# 378-piling-up Piling Up

- 场景: Problems & Solutions / 问题处理
- 句型: Problems keep piling up with ...
- 意思: 问题越积越多
- 用法: 用于说问题在不断累积。

## 例句

1. Problems keep piling up with the renovation.
   - 装修的问题越积越多。

2. Problems keep piling up with the new system.
   - 新系统的问题越积越多。

3. Problems keep piling up with the car lately.
   - 最近车的问题越积越多。

4. Problems keep piling up with the project deadline.
   - 项目截止前问题越积越多。

5. Problems keep piling up with the old building.
   - 老楼的问题越积越多。
