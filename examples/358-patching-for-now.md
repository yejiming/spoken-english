# 358-patching-for-now Patching For Now

- 场景: Problems & Solutions / 问题处理
- 句型: I'm just patching ... for now.
- 意思: 先临时修补
- 用法: 用于说只是暂时修补而非彻底解决。

## 例句

1. I'm just patching the code for now until we refactor.
   - 我先临时改改代码，等以后重构。

2. I'm just patching the leak for now with some tape.
   - 我先用胶带临时补一下漏水。

3. I'm just patching the website layout for now.
   - 我先临时修一下网站的布局。

4. I'm just patching the server config for now.
   - 我先临时改一下服务器配置。

5. I'm just patching the broken fence for now.
   - 我先临时修一下坏掉的栅栏。
