# 452-vibing-with Vibing With

- 场景: Feelings & Opinions / 感受观点
- 句型: I'm really vibing with ...
- 意思: 很来感觉了
- 用法: 用于说跟某事物特别合拍。

## 例句

1. I'm really vibing with this playlist right now.
   - 我现在听这个歌单很来感觉。

2. I'm really vibing with the aesthetic of this café.
   - 这家咖啡店的风格我很来感觉。

3. I'm really vibing with this new workspace setup.
   - 新的工位布置我很来感觉。

4. I'm really vibing with the energy at this event.
   - 这个活动的氛围我很来感觉。

5. I'm really vibing with this author's writing style.
   - 这个作者的写作风格我很来感觉。
