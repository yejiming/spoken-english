# 057-skipping-today Skipping Today

- 场景: Daily Life / 日常生活
- 句型: I'm skipping ... today.
- 意思: 今天就不做了
- 用法: 用于表示今天决定跳过某件事不做。

## 例句

1. I'm skipping breakfast today.
   - 我今天不吃早饭了。

2. I'm skipping my workout today.
   - 我今天不锻炼了。

3. I'm skipping the morning walk today.
   - 我今天不去晨走了。

4. I'm skipping laundry today.
   - 我今天不洗衣服了。

5. I'm skipping my skincare routine today.
   - 我今天护肤步骤就省了。
