# 415-getting-used-to Getting Used To

- 场景: Feelings & Opinions / 感受观点
- 句型: I'm getting used to ...
- 意思: 正在适应
- 用法: 用于表达逐渐习惯某种新变化。

## 例句

1. I'm getting used to waking up early for work.
   - 我正在慢慢习惯早起上班。

2. I'm getting used to living in a big city.
   - 我正在慢慢习惯住在大城市。

3. I'm getting used to cooking for myself.
   - 我正在慢慢习惯自己做饭。

4. I'm getting used to the new software at the office.
   - 我正在慢慢习惯公司的新软件。

5. I'm getting used to speaking English every day.
   - 我正在慢慢习惯每天说英语。
