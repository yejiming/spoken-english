# 253-backup-plan Backup Plan

- 场景: Social Plans / 社交安排
- 句型: If that falls through, we could ...
- 意思: 备用方案
- 用法: 用于提出万一计划泡汤后的替代方案。

## 例句

1. If that falls through, we could just order in.
   - 如果那个不行，咱们可以叫外卖。

2. If that falls through, we could try the new bar.
   - 如果那不行，可以去试试新开的酒吧。

3. If that falls through, we could do a movie night.
   - 如果那泡汤了，可以在家看电影。

4. If that falls through, we could hit up the arcade.
   - 如果那不行，可以去街机厅。

5. If that falls through, we could just chill at the park.
   - 如果那个不行，去公园放松也行。
