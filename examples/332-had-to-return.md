# 332-had-to-return Had To Return

- 场景: Problems & Solutions / 问题处理
- 句型: I had to return ... because it was broken.
- 意思: 退货了
- 用法: 用于说因为损坏而退货。

## 例句

1. I had to return the blender because it was broken.
   - 我退了搅拌机因为是坏的。

2. I had to return the headphones because they were broken.
   - 我退了耳机因为是坏的。

3. I had to return the monitor because it was broken.
   - 我退了显示器因为是坏的。

4. I had to return the chair because it was broken.
   - 我退了椅子因为是坏的。

5. I had to return the keyboard because it was broken.
   - 我退了键盘因为是坏的。
