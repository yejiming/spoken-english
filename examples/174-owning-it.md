# 174-owning-it Owning It

- 场景: Work & School / 工作学习
- 句型: I'm owning ... from now on.
- 意思: 从现在起我负责
- 用法: 用于说你从现在开始全权负责某件事。

## 例句

1. I'm owning the social media accounts from now on.
   - 从现在起社交媒体账号归我负责。

2. I'm owning the weekly status report from now on.
   - 从现在起周报归我负责。

3. I'm owning the client relationship from now on.
   - 从现在起客户关系归我负责。

4. I'm owning the testing process from now on.
   - 从现在起测试流程归我负责。

5. I'm owning the inventory tracking from now on.
   - 从现在起库存跟踪归我负责。
