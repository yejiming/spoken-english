# 49-confirm-whether Confirm Whether

- 场景: Social Plans / 社交安排
- 句型: I need to confirm whether we can ...
- 意思: 先确认安排。
- 用法: 用于核实能否成行。

## 例句

1. I need to confirm whether we can check out the new place
   - 我得确认我们能不能去看看那家新店。

2. I need to confirm whether we can hang out
   - 我得确认我们能不能一起待着。

3. I need to confirm whether we can celebrate a little
   - 我得确认我们能不能小小庆祝一下。

4. I need to confirm whether we can have a quick chat
   - 我得确认我们能不能聊几句。

5. I need to confirm whether we can stop by later
   - 我得确认我们能不能待会儿顺路过去。
