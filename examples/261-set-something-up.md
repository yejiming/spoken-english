# 261-set-something-up Set Something Up

- 场景: Social Plans / 社交安排
- 句型: Let me set something up for ...
- 意思: 我来安排
- 用法: 用于主动提出帮大家组织安排活动。

## 例句

1. Let me set something up for this Friday.
   - 这周五的事我来安排。

2. Let me set something up for the team.
   - 我来给团队安排个活动。

3. Let me set something up for your birthday.
   - 你的生日我来安排。

4. Let me set something up for after finals.
   - 期末考完的活动我来张罗。

5. Let me set something up for the long weekend.
   - 长周末的安排交给我。
