# 114-sorting-out Sorting Out

- 场景: Work & School / 工作学习
- 句型: I'm still sorting out ...
- 意思: 还在理清头绪
- 用法: 用于说你还在把某件复杂的事情理顺。

## 例句

1. I'm still sorting out the budget numbers.
   - 我还在理清预算数字。

2. I'm still sorting out the seating arrangement.
   - 我还在安排座位。

3. I'm still sorting out my class schedule.
   - 我还在理我的课表。

4. I'm still sorting out the technical issues with the server.
   - 我还在解决服务器的技术问题。

5. I'm still sorting out who's responsible for what.
   - 我还在理清各自的分工。
