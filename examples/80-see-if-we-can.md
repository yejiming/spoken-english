# 80-see-if-we-can See If We Can

- 场景: Problems & Solutions / 问题处理
- 句型: Let's see if we can ...
- 意思: 一起试试。
- 用法: 用于一起找办法。

## 例句

1. Let's see if we can miss the deadline
   - 我们看看能不能错过截止时间。

2. Let's see if we can lose the progress
   - 我们看看能不能丢掉进度。

3. Let's see if we can get this sorted out
   - 我们看看能不能把这件事处理好。

4. Let's see if we can open the app
   - 我们看看能不能打开应用。

5. Let's see if we can log in
   - 我们看看能不能登录。
