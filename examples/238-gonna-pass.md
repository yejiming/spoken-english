# 238-gonna-pass Gonna Pass

- 场景: Social Plans / 社交安排
- 句型: I'm gonna pass on ...
- 意思: 不去了
- 用法: 用于直接但友善地拒绝某个邀请。

## 例句

1. I'm gonna pass on the club tonight.
   - 我今晚就不去夜店了。

2. I'm gonna pass on the after-party.
   - 我就不去余兴派对了。

3. I'm gonna pass on poker night.
   - 我就不去打牌了。

4. I'm gonna pass on the hike this time.
   - 这次远足我就不去了。

5. I'm gonna pass on dessert.
   - 甜点我就不吃了。
