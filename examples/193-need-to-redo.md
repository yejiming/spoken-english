# 193-need-to-redo Need To Redo

- 场景: Work & School / 工作学习
- 句型: I need to redo ...
- 意思: 需要重做
- 用法: 用于说你得把某样东西推翻重来。

## 例句

1. I need to redo the entire spreadsheet.
   - 我需要重做整个电子表格。

2. I need to redo my lab report.
   - 我需要重做实验报告。

3. I need to redo the formatting on this document.
   - 我需要重做这个文档的格式。

4. I need to redo the calculations from scratch.
   - 我需要从头重做这些计算。

5. I need to redo the slides because of the new branding.
   - 因为新的品牌形象我需要重做幻灯片。
