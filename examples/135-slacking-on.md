# 135-slacking-on Slacking On

- 场景: Work & School / 工作学习
- 句型: I've been slacking on ...
- 意思: 一直在偷懒
- 用法: 用于承认你最近对某事不够上心。

## 例句

1. I've been slacking on updating my resume.
   - 我一直懒着没更新简历。

2. I've been slacking on my homework lately.
   - 我最近一直在偷懒不做作业。

3. I've been slacking on replying to work emails.
   - 我一直拖着没回工作邮件。

4. I've been slacking on preparing for the exam.
   - 我一直在偷懒没好好备考。

5. I've been slacking on my weekly reports.
   - 我一直拖着没写周报。
