# 369-traced-it-back Traced It Back

- 场景: Problems & Solutions / 问题处理
- 句型: I traced it back to ...
- 意思: 追溯到了
- 用法: 用于说找到了问题的根源。

## 例句

1. I traced it back to a faulty cable.
   - 我追溯到是一根坏线的问题。

2. I traced it back to a missing config file.
   - 我追溯到是缺了一个配置文件。

3. I traced it back to an outdated plugin.
   - 我追溯到是一个过时的插件。

4. I traced it back to a typo in the code.
   - 我追溯到是代码里的一个拼写错误。

5. I traced it back to the wrong API key.
   - 我追溯到是用了错误的API密钥。
