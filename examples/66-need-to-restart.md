# 66-need-to-restart Need To Restart

- 场景: Problems & Solutions / 问题处理
- 句型: I need to restart ...
- 意思: 先重开试试。
- 用法: 用于说需要重启。

## 例句

1. I need to restart find a backup plan
   - 我得重启找备用方案。

2. I need to restart the wifi to connect
   - 我得重启Wi-Fi 连接。

3. I need to restart miss the deadline
   - 我得重启错过截止时间。

4. I need to restart lose the progress
   - 我得重启丢掉进度。

5. I need to restart get this sorted out
   - 我得重启把这件事处理好。
