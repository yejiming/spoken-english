# 379-last-resort Last Resort

- 场景: Problems & Solutions / 问题处理
- 句型: As a last resort, I'm gonna ...
- 意思: 最后的办法
- 用法: 用于说在万不得已时采取的措施。

## 例句

1. As a last resort, I'm gonna factory reset my phone.
   - 实在没办法了，我要恢复出厂设置。

2. As a last resort, I'm gonna call a professional.
   - 实在没办法了，我要找专业人士。

3. As a last resort, I'm gonna buy a new one.
   - 实在没办法了，我要买个新的。

4. As a last resort, I'm gonna start the project over.
   - 实在没办法了，我要重新开始项目。

5. As a last resort, I'm gonna switch providers.
   - 实在没办法了，我要换服务商。
