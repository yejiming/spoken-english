# 124-running-into-issues Running Into Issues

- 场景: Work & School / 工作学习
- 句型: I keep running into issues with ...
- 意思: 总是碰到问题
- 用法: 用于说你在某方面反复遇到麻烦。

## 例句

1. I keep running into issues with the printer.
   - 我总是碰到打印机的问题。

2. I keep running into issues with the software update.
   - 我总是碰到软件更新的问题。

3. I keep running into issues with my login credentials.
   - 我总是碰到登录凭证的问题。

4. I keep running into issues with the new system.
   - 我总是碰到新系统的问题。

5. I keep running into issues with formatting the document.
   - 我总是碰到文档格式方面的问题。
