# 444-dying-to-try Dying To Try

- 场景: Feelings & Opinions / 感受观点
- 句型: I'm dying to try ...
- 意思: 超想试试
- 用法: 用于说非常期待尝试某事物。

## 例句

1. I'm dying to try that new ramen shop downtown.
   - 我超想试试市中心那家新拉面店。

2. I'm dying to try skydiving at least once.
   - 我超想至少试一次跳伞。

3. I'm dying to try the new VR headset.
   - 我超想试试新出的VR头显。

4. I'm dying to try making homemade pasta.
   - 我超想试试自己做意面。

5. I'm dying to try the dessert everyone's been talking about.
   - 我超想试试大家都在说的那个甜点。
