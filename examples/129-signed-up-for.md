# 129-signed-up-for Signed Up For

- 场景: Work & School / 工作学习
- 句型: I signed up for ...
- 意思: 报名参加了
- 用法: 用于说你已经注册或报名了某样东西。

## 例句

1. I signed up for the leadership workshop.
   - 我报名参加了领导力研讨班。

2. I signed up for an online coding course.
   - 我报名了一门在线编程课。

3. I signed up for the company volleyball team.
   - 我报名了公司的排球队。

4. I signed up for the morning shift next week.
   - 我报名了下周的早班。

5. I signed up for the advanced Excel training.
   - 我报名了高级Excel培训。
