# 031-probably-should Probably Should

- 场景: Daily Life / 日常生活
- 句型: I probably should ... soon.
- 意思: 大概该做了
- 用法: 用于表示某件事应该尽快去做了。

## 例句

1. I probably should go to bed soon.
   - 我大概该去睡觉了。

2. I probably should start making dinner soon.
   - 我大概该开始做晚饭了。

3. I probably should clean my room soon.
   - 我大概该收拾房间了。

4. I probably should do the dishes soon.
   - 我大概该洗碗了。

5. I probably should go grocery shopping soon.
   - 我大概该去买菜了。
