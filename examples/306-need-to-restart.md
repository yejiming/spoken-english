# 306-need-to-restart Need To Restart

- 场景: Problems & Solutions / 问题处理
- 句型: I need to restart ...
- 意思: 需要重启一下
- 用法: 用于表达你需要重新启动某个设备或程序。

## 例句

1. I need to restart my laptop — it's running really slow.
   - 我得重启笔记本电脑，太卡了。

2. I need to restart the router to fix the connection.
   - 我得重启路由器来修复网络连接。

3. I need to restart the app because it froze.
   - 我得重启这个应用，它卡住了。

4. I need to restart my phone — it's been acting up.
   - 我得重启手机，它一直出毛病。

5. I need to restart the printer — the job got stuck.
   - 我得重启打印机，打印任务卡住了。
