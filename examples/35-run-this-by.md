# 35-run-this-by Run This By

- 场景: Work & School / 工作学习
- 句型: I'm running this by ...
- 意思: 先让别人看一下。
- 用法: 用于征求意见。

## 例句

1. I'm running this by the meeting prep
   - 我把这个先给会议准备过目。

2. I'm running this by taking notes
   - 我把这个先给做笔记过目。

3. I'm running this by the slides
   - 我把这个先给这些幻灯片过目。

4. I'm running this by asking for feedback
   - 我把这个先给征求反馈过目。

5. I'm running this by the spreadsheet
   - 我把这个先给这个表格过目。
