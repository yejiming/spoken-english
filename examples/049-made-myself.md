# 049-made-myself Made Myself

- 场景: Daily Life / 日常生活
- 句型: I made myself ... this morning.
- 意思: 今早强迫自己做
- 用法: 用于描述今天早上逼自己去完成某件不太想做的事。

## 例句

1. I made myself go for a jog this morning.
   - 我今早强迫自己去跑了步。

2. I made myself eat a healthy breakfast this morning.
   - 我今早强迫自己吃了顿健康早餐。

3. I made myself get up at six this morning.
   - 我今早强迫自己六点起床了。

4. I made myself meditate this morning.
   - 我今早强迫自己冥想了。

5. I made myself stretch this morning.
   - 我今早强迫自己做了拉伸。
