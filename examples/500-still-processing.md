# 500-still-processing Still Processing

- 场景: Feelings & Opinions / 感受观点
- 句型: I'm still processing ...
- 意思: 还在消化中
- 用法: 用于说对某事还没完全想明白。

## 例句

1. I'm still processing everything that happened yesterday.
   - 我还在消化昨天发生的一切。

2. I'm still processing the news about the company changes.
   - 公司变动的消息我还在消化中。

3. I'm still processing the ending of that show.
   - 那部剧的结局我还在消化中。

4. I'm still processing the fact that I got the job.
   - 拿到这份工作这件事我还在消化中。

5. I'm still processing all the feedback I received.
   - 收到的所有反馈我还在消化中。
