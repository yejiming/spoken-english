# 281-always-wanted-to Always Wanted To

- 场景: Social Plans / 社交安排
- 句型: I've always wanted to try ...
- 意思: 一直想试试
- 用法: 用于表达你长期以来想尝试的事情。

## 例句

1. I've always wanted to try rock climbing.
   - 我一直想试试攀岩。

2. I've always wanted to try hot pot.
   - 我一直想试试吃火锅。

3. I've always wanted to try paddleboarding.
   - 我一直想试试桨板。

4. I've always wanted to try escape rooms.
   - 我一直想试试密室逃脱。

5. I've always wanted to try that speakeasy.
   - 我一直想试试那家隐藏酒吧。
