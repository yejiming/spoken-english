# 464-hyped-about Hyped About

- 场景: Feelings & Opinions / 感受观点
- 句型: I'm super hyped about ...
- 意思: 超级激动
- 用法: 用于说对某事非常兴奋期待。

## 例句

1. I'm super hyped about the new game coming out.
   - 新游戏要出了我超级激动。

2. I'm super hyped about the trip to Japan next month.
   - 下个月去日本的行程我超级激动。

3. I'm super hyped about seeing my favorite band live.
   - 能现场看到我最喜欢的乐队我超级激动。

4. I'm super hyped about the product launch tomorrow.
   - 明天的产品发布我超级激动。

5. I'm super hyped about the new season dropping tonight.
   - 新一季今晚上线我超级激动。
