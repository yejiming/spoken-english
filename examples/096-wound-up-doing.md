# 096-wound-up-doing Wound Up Doing

- 场景: Daily Life / 日常生活
- 句型: I wound up ... all afternoon.
- 意思: 结果一下午都在
- 用法: 用于描述一个下午不知不觉都花在了某件事上。

## 例句

1. I wound up cleaning all afternoon.
   - 我结果一整个下午都在打扫卫生。

2. I wound up napping all afternoon.
   - 我结果一整个下午都在睡觉。

3. I wound up cooking all afternoon.
   - 我结果一整个下午都在做饭。

4. I wound up binge-watching shows all afternoon.
   - 我结果一整个下午都在追剧。

5. I wound up reorganizing my closet all afternoon.
   - 我结果一整个下午都在整理衣柜。
