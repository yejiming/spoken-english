# 397-got-corrupted Got Corrupted

- 场景: Problems & Solutions / 问题处理
- 句型: My ... got corrupted somehow.
- 意思: 不知怎么损坏了
- 用法: 用于说文件或数据莫名损坏。

## 例句

1. My save file got corrupted somehow.
   - 我的存档不知怎么损坏了。

2. My USB drive got corrupted somehow.
   - 我的U盘不知怎么损坏了。

3. My database got corrupted somehow overnight.
   - 我的数据库一夜之间不知怎么损坏了。

4. My project folder got corrupted somehow.
   - 我的项目文件夹不知怎么损坏了。

5. My backup got corrupted somehow during transfer.
   - 传输过程中我的备份不知怎么损坏了。
