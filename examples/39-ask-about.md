# 39-ask-about Ask About

- 场景: Work & School / 工作学习
- 句型: I'd like to ask about ...
- 意思: 想礼貌询问。
- 用法: 用于正式一点地发问。

## 例句

1. I'd like to ask about the comments
   - 我想问一下这些批注。

2. I'd like to ask about the handout
   - 我想问一下讲义。

3. I'd like to ask about the summary
   - 我想问一下总结。

4. I'd like to ask about my notes
   - 我想问一下我的笔记。

5. I'd like to ask about the assignment
   - 我想问一下作业。
