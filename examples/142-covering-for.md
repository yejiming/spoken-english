# 142-covering-for Covering For

- 场景: Work & School / 工作学习
- 句型: I'm covering for ... this week.
- 意思: 在替别人顶班
- 用法: 用于说你在代替某人工作。

## 例句

1. I'm covering for Sarah this week.
   - 这周我在替Sarah顶班。

2. I'm covering for my manager this week.
   - 这周我在替我经理顶班。

3. I'm covering for the receptionist this week.
   - 这周我在替前台顶班。

4. I'm covering for a coworker who's on vacation this week.
   - 这周我在替一个休假的同事顶班。

5. I'm covering for the team lead this week.
   - 这周我在替组长顶班。
