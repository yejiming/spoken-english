# 116-make-sure Make Sure

- 场景: Work & School / 工作学习
- 句型: I need to make sure I ...
- 意思: 必须确认没问题
- 用法: 用于强调你需要确认或保证做到某件事。

## 例句

1. I need to make sure I save the file before closing.
   - 我得确保关闭前保存了文件。

2. I need to make sure I include all the references.
   - 我得确保把所有参考文献都列上。

3. I need to make sure I reply to the client by five.
   - 我得确保五点前回复客户。

4. I need to make sure I back up the database tonight.
   - 我得确保今晚备份数据库。

5. I need to make sure I bring my laptop to the meeting.
   - 我得确保开会时带上笔记本电脑。
