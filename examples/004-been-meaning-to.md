# 004-been-meaning-to Been Meaning To

- 场景: Daily Life / 日常生活
- 句型: I've been meaning to ...
- 意思: 一直想做还没做
- 用法: 用于说你惦记了很久的事。

## 例句

1. I've been meaning to clean out the closet.
   - 我一直想清理一下衣柜。

2. I've been meaning to try that new restaurant.
   - 我一直想去那家新餐厅试试。

3. I've been meaning to call my dentist.
   - 我一直想给牙医打个电话。

4. I've been meaning to fix the leaky faucet.
   - 我一直想修一下漏水的水龙头。

5. I've been meaning to return those library books.
   - 我一直想把那些图书馆的书还了。
