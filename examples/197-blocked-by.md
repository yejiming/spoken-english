# 197-blocked-by Blocked By

- 场景: Work & School / 工作学习
- 句型: I'm blocked by ...
- 意思: 被卡住了
- 用法: 用于说你因为某个外部障碍而无法继续。

## 例句

1. I'm blocked by a missing API key.
   - 我被缺少的API密钥卡住了。

2. I'm blocked by the approval that hasn't come through.
   - 我被还没下来的审批卡住了。

3. I'm blocked by a dependency from another team.
   - 我被另一个团队的依赖项卡住了。

4. I'm blocked by a server outage.
   - 我被服务器宕机卡住了。

5. I'm blocked by the legal review process.
   - 我被法务审核流程卡住了。
