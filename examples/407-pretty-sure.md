# 407-pretty-sure Pretty Sure

- 场景: Feelings & Opinions / 感受观点
- 句型: I'm pretty sure ... is going to work.
- 意思: 对方案有信心
- 用法: 用于表达对某个计划或方法会奏效的把握。

## 例句

1. I'm pretty sure this new strategy is going to work.
   - 我很确定这个新策略会奏效。

2. I'm pretty sure the revised schedule is going to work.
   - 我很确定调整后的日程会奏效。

3. I'm pretty sure his approach is going to work.
   - 我很确定他的方法会奏效。

4. I'm pretty sure the backup plan is going to work.
   - 我很确定备用方案会奏效。

5. I'm pretty sure our marketing campaign is going to work.
   - 我很确定我们的营销活动会奏效。
