# 009-in-a-bit In A Bit

- 场景: Daily Life / 日常生活
- 句型: I'm going to ... in a bit.
- 意思: 稍后就要做
- 用法: 用于说自己等会儿要去做什么。

## 例句

1. I'm going to take a nap in a bit.
   - 我过一会儿要小睡一下。

2. I'm going to run to the store in a bit.
   - 我过一会儿要去趟超市。

3. I'm going to start on dinner in a bit.
   - 我过一会儿要开始做晚饭。

4. I'm going to give her a call in a bit.
   - 我过一会儿要给她打个电话。

5. I'm going to clean up the kitchen in a bit.
   - 我过一会儿要收拾一下厨房。
