# 144-loaded-this-week Loaded This Week

- 场景: Work & School / 工作学习
- 句型: I'm loaded with ... this week.
- 意思: 这周任务超多
- 用法: 用于说这周你的某类工作特别多。

## 例句

1. I'm loaded with meetings this week.
   - 这周我的会排得满满的。

2. I'm loaded with assignments this week.
   - 这周我作业特别多。

3. I'm loaded with client calls this week.
   - 这周我的客户电话特别多。

4. I'm loaded with deadlines this week.
   - 这周我的截止日期特别多。

5. I'm loaded with training sessions this week.
   - 这周我的培训特别多。
