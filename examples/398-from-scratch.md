# 398-from-scratch From Scratch

- 场景: Problems & Solutions / 问题处理
- 句型: I have to start ... from scratch.
- 意思: 从头来过
- 用法: 用于说必须完全重新开始。

## 例句

1. I have to start the report from scratch.
   - 我得从头重新写报告。

2. I have to start the website from scratch.
   - 我得从头重新做网站。

3. I have to start my collection from scratch.
   - 我得从头重新收集。

4. I have to start the recipe from scratch.
   - 我得从头重新做这道菜。

5. I have to start the entire setup from scratch.
   - 我得从头重新搭环境。
