# 254-overdue-for Overdue For

- 场景: Social Plans / 社交安排
- 句型: We're overdue for ...
- 意思: 该聚一聚了
- 用法: 用于表示某个聚会或活动早该安排了。

## 例句

1. We're overdue for a hangout.
   - 咱们早该聚一聚了。

2. We're overdue for a road trip.
   - 咱们早该来趟自驾游了。

3. We're overdue for a dinner party.
   - 咱们早该办个晚宴了。

4. We're overdue for a game night.
   - 咱们早该搞个游戏之夜了。

5. We're overdue for a catch-up.
   - 咱们早该叙叙旧了。
