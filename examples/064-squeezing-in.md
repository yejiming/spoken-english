# 064-squeezing-in Squeezing In

- 场景: Daily Life / 日常生活
- 句型: I'm squeezing in ... before dinner.
- 意思: 晚饭前抽空做
- 用法: 用于表示趁晚饭前的空档赶紧做某件事。

## 例句

1. I'm squeezing in a quick workout before dinner.
   - 我在晚饭前抽空快速锻炼一下。

2. I'm squeezing in some reading before dinner.
   - 我在晚饭前抽空看会儿书。

3. I'm squeezing in a phone call before dinner.
   - 我在晚饭前抽空打个电话。

4. I'm squeezing in a shower before dinner.
   - 我在晚饭前抽空洗个澡。

5. I'm squeezing in some yoga before dinner.
   - 我在晚饭前抽空做个瑜伽。
