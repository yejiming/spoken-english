# 70-need-to-replace Need To Replace

- 场景: Problems & Solutions / 问题处理
- 句型: I need to replace ...
- 意思: 需要更换。
- 用法: 用于说东西坏了要换。

## 例句

1. I need to replace reset the password
   - 我得换掉重设密码。

2. I need to replace finish the upload
   - 我得换掉完成上传。

3. I need to replace charge the laptop
   - 我得换掉给笔记本充电。

4. I need to replace fix the microphone
   - 我得换掉修好麦克风。

5. I need to replace load the page
   - 我得换掉加载页面。
