# 132-barely-keeping-up Barely Keeping Up

- 场景: Work & School / 工作学习
- 句型: I'm barely keeping up with ...
- 意思: 勉强跟得上
- 用法: 用于说你在某方面很吃力地跟着节奏。

## 例句

1. I'm barely keeping up with the workload.
   - 我勉强跟得上这个工作量。

2. I'm barely keeping up with the lectures.
   - 我勉强跟得上课堂进度。

3. I'm barely keeping up with all the changes.
   - 我勉强跟得上所有这些变化。

4. I'm barely keeping up with the reading list.
   - 我勉强跟得上阅读书单的进度。

5. I'm barely keeping up with the team's pace.
   - 我勉强跟得上团队的节奏。
