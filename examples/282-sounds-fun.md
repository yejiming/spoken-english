# 282-sounds-fun Sounds Fun

- 场景: Social Plans / 社交安排
- 句型: That sounds fun — count me in for ...
- 意思: 听着挺好玩
- 用法: 用于表示你有兴趣并确认参加。

## 例句

1. That sounds fun — count me in for Saturday.
   - 听着挺好玩——周六算我一个。

2. That sounds fun — count me in for the trip.
   - 听着挺好玩——旅行算我一个。

3. That sounds fun — count me in for karaoke.
   - 听着挺好玩——唱歌算我一个。

4. That sounds fun — count me in for game night.
   - 听着挺好玩——游戏之夜算我一个。

5. That sounds fun — count me in for the cookout.
   - 听着挺好玩——烧烤算我一个。
