# 092-so-over-it So Over It

- 场景: Daily Life / 日常生活
- 句型: I'm so over ...
- 意思: 受够了
- 用法: 用于表达对某件事已经彻底厌烦了。

## 例句

1. I'm so over doing dishes every night.
   - 我受够了每天晚上洗碗。

2. I'm so over this rainy weather.
   - 我受够了这种阴雨天气。

3. I'm so over waking up early.
   - 我受够了早起。

4. I'm so over cooking the same meals.
   - 我受够了做一样的饭菜。

5. I'm so over my long commute.
   - 我受够了长时间通勤。
