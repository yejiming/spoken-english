# 123-wrapping-it-up Wrapping It Up

- 场景: Work & School / 工作学习
- 句型: I'm wrapping up ... before I leave.
- 意思: 收尾工作
- 用法: 用于说你在离开之前正在收尾某件事。

## 例句

1. I'm wrapping up this email before I leave.
   - 我走之前把这封邮件写完。

2. I'm wrapping up the meeting notes before I leave.
   - 我走之前把会议记录整理完。

3. I'm wrapping up my lab report before I leave.
   - 我走之前把实验报告收个尾。

4. I'm wrapping up the budget review before I leave.
   - 我走之前把预算审核收个尾。

5. I'm wrapping up the last few slides before I leave.
   - 我走之前把最后几页幻灯片弄完。
