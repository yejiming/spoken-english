# 276-finishing-up-early Finishing Up Early

- 场景: Social Plans / 社交安排
- 句型: I'll finish up early so we can ...
- 意思: 早点弄完
- 用法: 用于表示你会提前完成事情以便参加计划。

## 例句

1. I'll finish up early so we can grab dinner.
   - 我早点弄完，咱们好去吃晚饭。

2. I'll finish up early so we can hit the road.
   - 我早点弄完，咱们好出发。

3. I'll finish up early so we can get good seats.
   - 我早点弄完，咱们好占个好位子。

4. I'll finish up early so we can avoid traffic.
   - 我早点弄完，咱们好避开堵车。

5. I'll finish up early so we can pregame.
   - 我早点弄完，咱们好先喝一轮。
